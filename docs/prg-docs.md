# PRG Documentation

Status note: this document is the living index of the PRG (parameter-research-graph / optimization graph). It is **not** finished — see *Outstanding work* — and it must not be cited as "complete" while coupling work is in flight.

## 1. Purpose

The PRG is Alea’s parameter- and equation-bound research graph. It maps every tunable parameter, derived quantity, gate, and bound to its governing equation, units, citation(s), and the coupling path that reaches it through a DAQ. A node that floats (no coupling edge, no DAQ) carries little value: the standing program is to eliminate floating nodes and to document each node once its physics/economics coupling exists.

## 2. Authoritative artifacts

| Artifact | Role |
|---|---|
| `config/prg.yaml` | Served artifact — the baked graph. Hand-editing forbidden. |
| `config/prg_ingest/` (untracked scratch) | Retired ingest source; zero production callers. Reference only. |
| `prg/` | Main code in `service.py`, models in `views.py`. |
| `docs/prg-status.md` | Short status of the last audit run. |
| `docs/param_coupling_worklist.md` | Classified inventory of every uncoupled node and its coupling class. |
| `docs/research/<slug>/README.md` | Per-topic research, decisions, rejected options, local sources. |
| `sources/INDEX.md` + local copies | Archived external literature. No load-bearing URL is left unarchived. |

## 3. Invariants

- Every node must belong to a DAQ. Floating / uncoupled nodes are a defect.
- Every node carries units.
- No node-level `source` is the sole provenance (the citation register joins equations and node sources separately).
- Equations are regenerated by the generator; `prg.yaml` is baked, not typed in.
- Bake rewrites whole files (`default: null`, append-not-sorted ids). Re-bake; do not hand-patch.
- Parameters use physics / economics / research references (arXiv, IEEE, textbooks, Chinese literature); IRENA is not over-indexed.

## 4. Coupling graph status

Measured after batch 101: `load_graph().uncoupled()` is **empty**, tombstones included. Older figures (702, 422/488, 76, 16) are stale.

**Tombstones are coupled by forwarding equalities (batch 101).** A retired id cannot be an operand: `_deprecated_reach` refuses any equation or edge that reads it, so no quantity can depend on a dead name. It *can* be the determined side of a forwarding equality `old = successor`, which makes the old id report the live value instead of its frozen default. `ParameterGraph._is_forwarding` admits exactly that shape: relation `eq`, the tombstone the only determined variable and alone on the left, not read by the right, no free variables. Twelve ids forward to the node `deprecated_by` names. Three attainment ratios (`employment_attainment_local/women/youth`) are the achieved share over a targeted share; the retired target ids were replaced by new `*_employment_target_share` nodes (defaults 0.3, 0.15, 0.25, the values the dead ids carried). `pm25_relative_risk_per_kt` is the per-concentration risk times the dispersion factor (1/(ug/m3) x ug/m3/(kt/year) = 1/(kt/year)). Setting a computed tombstone is not refused (its value is the graph's output); setting a tombstone nothing computes still is.

**`choose` (batches 98 and 99).** A categorical has no arithmetic, so it could not be an equation operand. The DSL now has `choose(selector, level_a=expr, level_b=expr, ...)`: the selector must be a categorical parameter, the branches must cover its `categories` exactly (a missing or invented level is a graph load error), and only the live branch is evaluated or differentiated. The selector is a symbol; level names are not. All branches share a dimension (a literal `0` adopts its siblings'). A level table holds bare numbers, so a dimensioned result multiplies a one-unit anchor node (`rate_unit_per_year`, `duration_unit_years`, `latency_unit_ms`, `warming_unit_degc`, `cost_unit_usd`). Sensitivity skips string-valued symbols; the level names stay in the value mapping because `choose` reads its selector there. All 41 categoricals are now operands of `choose` equations. Literature fixes the shape where it exists (Lloyd 1982, Mullner 2013 and Clauset et al. 2004 for clustering exponents; IPCC AR6 SPM Table SPM.1 for SSP warming; Jordan and Kurtz 2013 for degradation; Faruqui and Sergici 2010 for time-of-use peak reduction). The level values are mostly stated assumptions ordered as the sources order them; each equation says so in its `reference`. `min` and `max` have no derivative rule, so a branch must not use them.

**Records (batch 100).** The 19 non-scalar stubs (record sets, free text, procedures) are retyped from the 500000 placeholder to 0/1 presence flags, each gating one stated-assumption quantity (same pattern as batch 97). The flag is the presence of the record, not its content; the content still has no type in `ParameterType`.

Batches 94 and 95 coupled 69 boolean flags. The worklist had counted them as "categorical", but a `bool` is a scalar in {0, 1}, so only 41 nodes are true categoricals. Each flag now gates one quantity, flag x exposure (x share), in a derived node with a stated unit: operations and maintenance flags gate a cost saving (condition-based, reliability-centred and risk-based maintenance, AMI, billing, CIS, work and asset management systems, cyber response, backup, OMS SAIDI); revenue-protection flags gate bad debt or arrears recovered (payment plans, prepayment metering, arrears management, disconnection protection, bill-shock protection); market-design flags gate a spread on merchant volume (day-ahead, intraday, real-time, balancing, ancillary, coupling, CfD, storage dispatch) or a dispatch-cost saving (SCED, unit commitment); network flags gate congestion or loss relief (phase shifting, topology switching, voltage optimisation, DG placement, DER management); legal, tax and lender-security flags gate a recovered, forgone or accelerated amount (direct agreement, step-in, assignment, change of control, cross-default, MAC, tax holiday, treaty, thin capitalisation, transfer pricing, PPA clauses); and ESG flags gate a spread cut or delay cost avoided. The exposures and shares are stated assumptions, each its own node, and are not measurements; the flags now carry unit `1` so the dimension check reads them. This reverses the earlier decision that fourteen market-design switches stay out of the arithmetic; the pinned register in `tests/ci/test_prg.py` now holds only `cross_border_trading`.

Batch 93 coupled six: `reserve_accounts` to debt-service reserve cover in years (Yescombe; the dimension check refused a "months" unit, so the node is in years); `coal_retirement_schedule` to the surviving coal fleet fraction exp(-rate x offset); and the four 0/1 market and maintenance switches as gates on the quantity they switch: `strategic_bidding` (Lerner markup on marginal cost), `virtual_bidding` (admitted virtual volume), `financial_transmission_rights` (congestion rent passed to holders, Hogan 1992) and `maintenance_schedule_optimisation` (downtime saving). The dead-knob test anchor moved from `ac_voltage_limit` to `line_outage_start`.

Batch 91 coupled 20 more typed nodes, each through an identity with a stated base:
- Five sector electrification shares x a new sector final-energy-demand base (agricultural machinery, construction machinery, ports, airports, mining), giving electric TWh/year.
- `ev_share_new_sales` x new vehicle sales; `irrigation_coverage` x arable land; `capital_gains_tax` x realised gains.
- `cvar_alpha` and `cvar_omega` through the Rockafellar-Uryasev representation, CVaR = VaR + E[(L-VaR)+]/(1-alpha), and the mean-CVaR mixture; `probability_weight` x scenario cost.
- `nuclear_lead_time` through an interest-during-construction factor (e^(rT)-1)/(rT) on `capex_nuclear`; the rate is treated as continuously compounded.
- `climate_sensitivity` through equilibrium warming S log2(C/C0), and `sea_level_rise` bounded above by the committed sea level (Levermann et al. 2013, 2.3 m per degree, a multi-millennial commitment).
- `number_of_retailers` -> equal-share HHI 10000/N -> `retail_competition` = 1 - HHI/10000 (now derived); `microgrid_deployment` over `connections_per_year`; `hydro_reservoir_level` x reservoir capacity; `renewable_curtailment_limit` x renewable generation; `water_pollution_load` over discharge volume.
Bases (sector energy, vehicle sales, arable land, gains, loss figures, effluent volume, reservoir capacity, CO2) are new exogenous nodes with stated-assumption defaults. `exchange_rate_volatility` stays open on purpose: it is declared per year, but lognormal quantiles scale with sigma x sqrt(t), which that unit cannot express.

Batch 90 coupled three clusters. (1) The balance of payments, after IMF BPM6: `current_account_balance` = goods-and-services balance - interest on `external_debt` + `official_development_assistance`; `balance_of_payments` = current account + `foreign_direct_investment` + other capital flows; `foreign_exchange_reserves_end` = reserves + balance x a one-year step. The first draft of the reserves identity added a stock to a flow and the dimension check refused it. (2) Annual start-up spend for coal and gas, cost per start x starts per year (NREL cycling-cost study). (3) `hazard_event_rate_total`, the sum of the heatwave, cold-snap and extreme-weather rates (Poisson superposition). Starts per year, the interest rate and the goods balance are stated assumptions.

Batch 89 coupled `capex_gravity_storage` into `gravity_storage_capex_usd_per_kw` (energy cost times a new 8-hour `gravity_storage_duration`, the battery power/energy split) and added `gravity_storage_energy_mwh` = nameplate x duration, the base the storage bound note said was missing.

Batch 88 coupled `fishing_vessel_fuel` to a new derived `fishing_fleet_fuel_energy` (MWh/year) through a new exogenous `diesel_energy_content_mwh_per_litre` (IPCC 2006 Vol. 2 Ch. 1 Table 1.2, 43.0 MJ/kg, archived, with an assumed 0.84 kg/L density), and gave `ev_adoption_timeline` and `electrification_timeline` derived logistic rates, r = ln(81)/T (the 10 to 90 percent rise time; a derivation, no archived copy).

Batch 87 typed six placeholders where a reading is defensible (`ac_voltage_limit` kV, `mining_demand_growth` MW, `buffer_zones` m, `interannual_variability` coefficient of variation, `carbon_credit_vintage` calendar-year label, `exchange_rate_usd_local` LCU/USD with a new `LCU` currency dimension). Each default is a stated assumption. They remain uncoupled: typing is not coupling.

Batch 86 added the morbidity term to the DALY: `health_impact_morbidity` (cases/year, via a `case = person` alias in `units.py`), `morbidity_disability_weight` and `morbidity_episode_duration` now enter `dalys_per_year` as YLD = cases x weight x duration (WHO 2020, archived). Batch 85 coupled `ev_battery_size` and `ev_efficiency` into the new derived `ev_range_km` (km), `mining_haulage` and `mining_hydrogen_haulage` through a part-of-total bound, and `adaptation_benefits` and `adaptation_costs` into the new derived `adaptation_net_benefit` (USD/year).

The remaining numeric nodes have no base node to attach to, such as `startup_cost_*`, `external_debt` and `sea_level_rise`.

## 5. Coupling classes

- Product couplings: direct level equations.
- Definition products: identity/survey/convention-derived materialized quantities.
- Threshold gates: bounded decision nodes (≤ / ≥ finite values).
- DAQ register entries: qualitative nodes whose only link is DAQ participation.

## 6. Documentation per node / parameter

Name, stable id, role (primary / auxiliary / derived / gate), unit, physical/economic meaning, governing equation (`rule_id`), DAQ, citation(s) archived under `sources/` or `docs/research/<slug>/`, valid domain/default, verification status.

## 7. Documentation per equation

`rule_id`, LHS (for inequalities this is the **boundee**, not the field-named "target"), RHS and unit map, internal/dummy nodes, research provenance, derived-vs-declared, verification (static parse, dimensional check, bake check, scenario oracle).

## 8. Citations and sources

- Numbers in prose come only from an actual run.
- Every paper, theorem, or doc a claim rests on is archived locally under `sources/` or `docs/research/<slug>/`, recorded in `sources/INDEX.md`. URLs alone are not proof.

## 9. Pinned registers

The ScenarioAudit skipped count, the determined-variable count (544), the citation register (315), the dead-knob count and the strength tiers are pinned in `tests/ci/test_prg.py`. Each coupling batch that adds an equation moves them; the earlier 298/305 and 603/610 mismatches were pins that lagged the committed batches 82-84, not a tier-logic defect. Edges for a new equation must be declared in `relationships:` (`test_every_equality_declares_an_edge_from_each_symbol_it_reads`).

## Explorer UI

`uv run alea prg ui [--port 8765]` serves a local page on 127.0.0.1 (stdlib server, no install). It lists and searches the nodes, shows a node's definition, the equations that determine it and read it, a neighbourhood graph, and a what-if panel. The what-if calls `propagate_change`, the function behind `alea prg propagate`, and shows a step-by-step cascade with each equation and its operand values. It never writes `config/prg.yaml`. The neighbourhood diagram zooms (wheel or buttons) and pans (drag). The Table view groups every parameter by category, is searchable with the same filters, and has an inline value box on each settable row that feeds the same what-if. Saved sets are written to `data/processed/prg_whatifs.json` (git-ignored) and reload with one click. The toolbar prints the open node or every equation. Only settable nodes accept a value; a computed node is refused with the graph's own reason.
